# Selios — instaladores

Instaladores do **Selios**, o assistente de reuniões da Selia.

- **Windows:** baixe `Selios-Setup-<versão>.exe` na [versão mais recente](https://github.com/rafaelferreira-del/selios-instaladores/releases/latest) e abra.
- **Mac:** baixe `Selios-<versão>-arm64.dmg` (Apple M1/M2/M3/M4) ou `-x64.dmg` (Intel).

Depois de instalado, o Selios se atualiza sozinho a partir daqui.

Este repositório só tem instaladores: o código-fonte não fica aqui, e nenhum dado de cliente ou de reunião passa por ele.
